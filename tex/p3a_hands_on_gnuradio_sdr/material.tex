\section*{Material and requirements}

For this session, you will need:
\begin{itemize}
    \item The latest version of GNU Radio installed on your computer (for further information, see INSTALL.md on the course's GitHub) ;
    \item The custom \texttt{gr-210X} GNU Radio package installed (for further information, see INSTALL.md on the course's GitHub);
    \item The SDR platform composed of a DE10-Nano board and a custom RF PCB ;
    \item An Ethernet cable to connect your computer to the DE10-Nano;
    \item An antenna.
\end{itemize}
