\section*{Objectives}

\begin{itemize}
    \item Discover the Nucleo MCU board and its programming tools ;
    \item Learn the basics of bare metal embedded programming, Hadware Abstraction Layer (HAL), General-Purpose Inputs-Outputs (GPIOs), interrupts and timers ;
    \item Acquire and observe your first audio signals ;
    \item Learn how to debug an embedded program by logging/tracing and using a physical debugger.
\end{itemize}
