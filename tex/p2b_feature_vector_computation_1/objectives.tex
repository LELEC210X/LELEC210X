\section*{Objectives}

\begin{itemize}
    \item Offload the memory transfer from the ADC using a DMA channel ;
    \item Understand the fixed-point representation compared with floating-points ;
    \item Process the acquired audio samples to compute a mel-vector for each acquisition block ;
    \item Assemble mel-vectors into feature vectors using the double buffering technique for continuous acquisition.
\end{itemize}
